
# Student Database Practice

## About
A beginner-friendly MySQL project for practising
database fundamentals and CRUD operations:
Create, Read, Update, and Delete.

## Database Details
- Database: StudentDatabase
- Table: Students

### Table Attributes
- StudentID: Primary key, generated automatically
- StudentName: Student's name
- Email: Unique email address
- Mobile: Student's mobile number
- City: Student's city

## Features
- Create a database and table
- Insert sample student records
- Display all student records
- Search for a student by ID
- Update a student's city
- Delete a record using a SQL query

## Technologies Used
- MySQL
- SQL

## How to Run
1. Install MySQL Server.
2. Open MySQL Workbench or another SQL client.
3. Connect to your MySQL server.
4. Open student_database_practice.sql.
5. Execute the script.
6. Review the output of the SELECT queries.

## CRUD Operations
- CREATE: INSERT INTO
- READ: SELECT
- UPDATE: UPDATE
- DELETE: DELETE

## Learning Objectives
- Understand tables and columns.
- Learn about primary keys and unique constraints.
- Practise SQL CRUD operations.
- Use WHERE clauses to select specific records.

## Notes
- The sample student information is fictional.
- Always check the WHERE condition before running
  UPDATE or DELETE statements.
- This is a beginner practice project.
